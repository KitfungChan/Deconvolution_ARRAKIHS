# Deconvolution_ARRAKIHS

This repository contains the code associated with the paper: "ARRAKIHS preparation: a hybrid LSR-diffusion image deconvolution framework" (Chen et al., in prep.). It implements the training pipelines for the diffusion model, and includes evaluation scripts for the completeness, purity and Distance to nearest neighbor. The figures/ folder contains the Jupyter notebooks used to generate all figures in the paper.
